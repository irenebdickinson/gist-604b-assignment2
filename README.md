# gist-604b-assignment2
GIST 604B Assignment 2: QGIS Desktop GIS Projects

Overview:
This repository demonstrates basic skills in QGIS. It shows project files and map screenshots created by me corresponding to tutorials under the same name. Each tutorial has a saved .qgz file in the Projects folder and .png screenshot in the Outputs folder. 

The skills practiced here  include map composition, coordinate reference system management, attribute table editing and querying, importing tabular data, vector and raster styling, terrain analysis, and attribute- and location-based joins and queries.

Software Environment:

QGIS Version: 
4.2.3
"Belem do Para"
No Plugins Used

Operating System:

Windows 10 Home
