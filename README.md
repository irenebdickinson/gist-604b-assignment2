# gist-604b-assignment2
GIST 604B Assignment 2: QGIS Desktop GIS Projects

Overview:
This repository demonstrates basic skills in QGIS. It shows project files and map screenshots created by me corresponding to tutorials under the same name. Each tutorial has a saved .qgz file in the Projects folder and .png screenshot in the Outputs folder. 

The skills practiced here  include map composition, coordinate reference system management, attribute table editing and querying, importing tabular data, vector and raster styling, terrain analysis, and attribute- and location-based joins and queries.

Skills Demonstrated:

-Loading vector and raster data and building a map project from scratch

-Designing a map layout with a title, legend, scale bar, and north arrow, and exporting it

-Working with coordinate reference systems (CRS), including on-the-fly reprojection and saving layers in a new projection

-Exploring, filtering, and selecting features in the attribute table

-Querying data with expressions and the Field Calculator

-Importing CSV and spreadsheet data and creating point layers from coordinate columns

-Symbolizing vector data with single, categorized, and graduated styles, and adding labels

-Styling raster data (singleband pseudocolor, hillshade) and performing basic terrain analysis

-Attribute table joins between spatial layers and non-spatial tables

-Spatial joins to transfer attributes between layers based on location

-Spatial queries to select features by their geometric relationship to other layers

-Finding and downloading free elevation data (GMTED2010) from USGS EarthExplorer

-Clipping a raster to an area of interest with GDAL's Clip Raster by Extent

-Generating hillshade and contour lines from a digital elevation model

-Smoothing contour geometries and exporting vector data to KML for viewing in Google Earth




Reflection:

Completing these tutorials made spatial joins and attribute (table) joins much clearer to me. The step-by-step instructions showed how an attribute join links a layer to a table through a shared field, while a spatial join connects features based on where they are located, and seeing both results in the attribute table made the difference concrete. The main challenge was that the version of QGIS I used did not always match the version shown in the tutorials, so some menus, tool names, and dialog layouts looked different from the screenshots. This caused a few small errors, and I had to search the Processing Toolbox or find where a setting had moved in order to finish those steps. Working through those differences taught me to understand what each tool does instead of only following the instructions click by click. I anticipate using these skills in future GIS positions that I may have. The terrain tutorial will especially be helpful with my anticipated area of interest in conservation related GIS.
